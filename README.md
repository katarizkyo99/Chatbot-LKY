# "What Would Lee Kuan Yew Do?" Chatbot

An AI-powered persona chatbot trained on Lee Kuan Yew's biographical data, historical speeches, and memoirs. The chatbot answers questions across geopolitics, history, economic policy, and life philosophy, responding strictly in the direct, pragmatic, and analytical tone of Singapore's founding Prime Minister.
